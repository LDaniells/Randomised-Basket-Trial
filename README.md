Code for the paper titled "Practical Recommendations for Designing, Simulating and Analysing Randomised Basket Trials"

The RandomisedCode file contains simulation code for 7 different analysis models for a randomised basket trials, with JAGS code for each model. Each simulation code calibrates for both:
(i) a single efficacy criteria and 
(ii) basket-specific criteria.

Code is also provided for investigations into the number of simulation iterations, calibration of model parameters and misalignment between current and historic data.
